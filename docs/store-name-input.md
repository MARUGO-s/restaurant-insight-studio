# 店舗名の候補選択と自由入力

## 仕様

店舗名は編集可能なコンボボックス。右の矢印で全店舗のプルダウンを開き、文字入力で候補を絞り込む。候補にない店舗名も、そのまま調査に使用できる。選択後も編集可能。候補は公式 https://marugo-s.com/ の2026-11-01掲載23店舗を `src/StoreNameInput.tsx` に収録する。公式一覧変更時にこの定義を更新する方式であり、自動同期ではない。名称内の空白・英字の大小・全半角を候補検索時のみ吸収し、自由入力値は勝手に書き換えない。

店舗選択はAppの既存 `storeName` と `storeUrl`、`siteUrls.tabelog` に反映する。ユーザーの追加要望により公式サイト・食べログURLを同時に自動入力する（当初のURL非連動仕様を置換）。初期表示のマルゴ四谷も公式サイト・食べログを設定。URLは後から自由に編集でき、自由入力中は手修正したURLを上書きしない。一覧にない店舗はURLも手入力する。グループ名・重点調査・他媒体URL・媒体の選択オン/オフを維持し、食べログを外していた場合は勝手に有効化しない。選択・矢印・IME変換で分析を開始しない。入力必須、既存送信処理、認証、API、DB、料金計測には変更なし。

## 検証と公開状態

候補選択・任意入力・URL連動を2026-11-01に本番公開し、配布ファイルの一致と公開画面を検証済み。[公開記録](release-2026-11-01.md)を参照。`node scripts/store-name-check.cjs` で23店舗の重複なし、空白を無視した検索、自由入力、必須属性、App既存stateへの接続を検証。追加前のコンポーネント不存在でREDを確認し、追加後GREEN。

`store-name-browser-check.cjs` は実コンポーネントと既存CSSを使ったサンプルフォーム。外部通信を遮断したChromeで選択、自由入力値の送信データ、他欄保持、意図しない送信なし、上下キー・Enter・Escape・Tab・IME、空欄拒否、390/768/1100px幅での横はみ出しと末尾店舗選択を確認する。実Supabase保存・有料分析は行わない。サンプルの送信試験は本番APIの疎通検査ではない。フォント取得は遮断し既存sans-serifフォールバックを使用する。

URL連動の追加検証：公式23サイトを取得し、リンクまたは検索で見つけた食べログの23店舗トップページをすべて取得してタイトル・店舗エリアを照合した。対応は[店舗URL一覧](store-url-catalog.md)に記録。Chromeで全23店舗を順に選び、公式・食べログの両URL一致、両URLの手修正と送信値保持、キーボード選択、他欄保持を検証。URL連動前に期待URLとの差でREDを確認し、実装後GREEN。表示回帰・型検査を含むbuildも成功。この段階の検証は公開前。公開後の確認は公開記録を参照。有料分析は未実行。

実行には既存のPlaywrightとChromeを使用する。`PLAYWRIGHT_MODULE` にPlaywrightのパス、`STORE_QA_DIR` にHermes scratch内の出力先を指定して `node scripts/store-name-browser-check.cjs` を実行する。依存package/lockは変更しない。

独立レビューも阻害問題なしで通過。別コンテキストで全23店舗のURL対応とブラウザ試験を再確認し、実Appを認証/APIのインメモリモックで動かして、初期URL、食べログOFF維持、他媒体・追加媒体・グループ名・重点事項の保持と送信payloadを確認した。実日本語IMEとSafariによる変換確定は未検証（合成IMEイベント試験のみ）。本番公開・実API接続の証明ではない。

店舗入力とレポート品質改善の各検証・独立レビューを完了し、ユーザー承認後に同時公開した。有料の実生成試験は未実施。
