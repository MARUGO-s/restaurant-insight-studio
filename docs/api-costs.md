# API料金の未確定記録

料金明細は生成リクエストの試行単位です。再試行が成功しても、中断した前の試行の料金は別に残します。未確定分は合計に含めず、0ドルとは扱いません。

ストリーミング中も応答IDと受信済み利用量を保存します。xAIの通信が中断した場合は、同じ応答IDをGETして結果を回収し、新しい生成リクエストを発行しません。最終応答で利用量が確認できたときだけ料金を確定します。失敗応答でも利用量があれば計上します。

「未確定分を再確認」は、ログイン中のユーザーに属するxAIの記録を最大4件照会します。作成後1分以上経過し、直近5分に確認していない記録が対象です。記録の所有者・未確定状態を更新時にも検証し、元の料金基準日やレポートとの関連は変えません。

応答IDがない記録、保存期限を過ぎた応答、提供元に利用量が残っていない応答は回復できません。過去の値を推測で補完せず、その理由を明細に表示します。中断の詳細はAPIキーを除去して保存し、調査本文や思考過程を料金のメタデータには含めません。

## 2026-11-01の中断調査

本番の旧コードは例外名・中断メッセージ・最後のSSEイベントを料金記録に保持していません。ジョブのエラーは後続の成功時に消えるため、現在のDBとログだけでは4件の直接原因を断定できません。保存済み応答のエラーをGETで照会するか、新しい診断記録が必要です。
